## 🎛️ **Barra de Acessibilidade:**

### **Funcionalidades Disponíveis:**
- 🔆 **Troca de Contraste:** Alterna entre modo normal e alto contraste
- 📏 **Ajuste de Fonte:** Botões para aumentar/diminuir tamanho da fonte (80% - 150%)
- 🔄 **Reset:** Restaura configurações padrão
- 💾 **Persistência:** Configurações salvas automaticamente

### **Como Usar:**
1. **Contraste:** Clique no botão com ícone de lua/sol
2. **Fonte:** Use os botões + e - para ajustar tamanho
3. **Reset:** Clique em "Reset" para restaurar padrões
4. **Persistência:** Configurações são mantidas entre sessões
